# Invest Navigator

Статический MVP сайта для первичного анализа рыночных сегментов и компаний. Проект сделан на HTML, CSS и JavaScript без backend, React и сборщика. Данные хранятся в JSON-файлах.

## Как открыть сайт

Для демонстрации одним файлом на Windows x64 используйте:

```text
dist\InvestNavigatorDemo.exe
```

Можно просто скопировать этот файл на другой Windows x64 ПК и запустить двойным кликом. `exe` содержит HTML, CSS, JavaScript и JSON внутри себя, поднимает локальный сервер и автоматически открывает сайт в браузере. Консольное окно нужно оставить открытым на время демонстрации; закрытие окна останавливает сайт.

По умолчанию лаунчер пробует `http://127.0.0.1:5500/`; если порт занят, выбирает другой свободный локальный порт и печатает фактический адрес в консоли.

Рекомендуемый способ для локальной работы на Windows:

1. Запустите `start.bat` из корня проекта.
2. Откройте `http://127.0.0.1:5500/`.

`start.bat` принудительно освобождает порт `5500`, если он занят, и запускает локальный сервер из корня проекта.

Альтернативно можно запустить локальный статический сервер вручную из корня проекта:

```bash
python -m http.server 5500 --bind 127.0.0.1
```

После запуска сайт будет доступен по адресу `http://127.0.0.1:5500/`.

Важно: страницы используют `fetch` для загрузки JSON, поэтому открытие HTML напрямую через `file://` может быть ограничено браузером.

## Как пересобрать exe

Сборка демонстрационного файла требует установленный .NET SDK 10 на машине разработчика:

```powershell
dotnet publish .\launcher\InvestNavigatorDemo\InvestNavigatorDemo.csproj -c Release -r win-x64 --self-contained true -o .\dist
```

После изменения HTML, CSS, JavaScript или JSON нужно выполнить эту команду заново, потому что сайт встраивается внутрь `dist\InvestNavigatorDemo.exe` на момент публикации.

Дополнительные параметры лаунчера:

```powershell
.\dist\InvestNavigatorDemo.exe --port 5600
.\dist\InvestNavigatorDemo.exe --no-open
```

## Структура файлов

- `dist/InvestNavigatorDemo.exe` — переносимый демонстрационный Windows x64 файл с сайтом внутри.
- `launcher/InvestNavigatorDemo/` — исходный код .NET-лаунчера для сборки `exe`.
- `index.html` — главная страница с поиском и 6 сегментами рынка.
- `sector.html` — страница сектора из URL-параметра `sector`.
- `company.html` — карточка компании из URL-параметра `ticker`.
- `screener.html` — скринер компаний с поиском, фильтрами и сортировкой.
- `methodology.html` — описание показателей и дисклеймер.
- `css/style.css` — единый адаптивный стиль сайта.
- `js/app.js` — логика главной страницы.
- `js/search.js` — глобальный поиск в header.
- `js/sectors.js` — загрузка и отображение страницы сектора.
- `js/company.js` — загрузка и отображение карточки компании.
- `js/screener.js` — фильтрация, сортировка и обновление таблицы скринера.
- `data/sectors.json` — список рыночных сегментов.
- `data/companies.json` — учебная база компаний.

## Данные

Все компании и показатели в `data/companies.json` являются учебными и примерными. Они не являются актуальными рыночными данными, прогнозом, рекомендацией или утверждением о реальном финансовом состоянии конкретных эмитентов.

## Как добавить компанию

1. Откройте `data/companies.json`.
2. Добавьте объект с полями:
   `name`, `ticker`, `sector`, `sectorSlug`, `description`, `pe`, `pb`, `roe`, `dividendYield`, `debtLevel`, `score`, `strengths`, `risks`, `conclusion`.
3. Убедитесь, что `sectorSlug` совпадает со slug сектора из `data/sectors.json`.
4. Проверьте компанию в скринере и на странице `company.html?ticker=ВАШ_ТИКЕР`.

## Как добавить сектор

1. Откройте `data/sectors.json`.
2. Добавьте объект с полями `id`, `title`, `slug`, `description`, `riskLevel`, `marketMood`.
3. Добавьте связанные компании в `data/companies.json`.
4. Проверьте карточку на главной и страницу `sector.html?sector=ВАШ_SLUG`.

## Будущее подключение Python/FastAPI

Статическая структура уже отделяет представление от данных. Для подключения backend можно:

1. Создать FastAPI-приложение с эндпоинтами `/api/sectors`, `/api/companies`, `/api/companies/{ticker}`.
2. Перенести JSON-данные в базу данных или оставить их как первичный seed.
3. Заменить пути `data/*.json` в JavaScript на API-эндпоинты.
4. Добавить серверную валидацию данных, расчет скоринга и обновление показателей по расписанию.
